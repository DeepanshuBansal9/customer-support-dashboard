# Customer Support Dashboard

A responsive Customer Support Dashboard built using React.js, Tailwind CSS, Zustand and Axios.

## Features

- Dashboard statistics
- Customer support ticket management
- Search tickets
- Filter by status
- Filter by priority
- Update ticket status
- Ticket details page
- Customer information
- Ticket conversation history
- Loading state
- Error state
- Empty state
- Responsive UI
- REST API integration
- Zustand state management

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Zustand
- Axios
- React Router
- JSON Server
